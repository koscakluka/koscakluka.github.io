---
title: LLMs are the missing piece, but only a missing piece
date: 2026-08-26
unpublished: true
---

One of the thoughts that keeps coming back to me is how great LLMs are in those
holes where nothing fitted before. Need someone to provide a clean review of a
text - very nice. Need a summary of changes in a codebase - works great. Want
to parse a blob of text and images with unpredictable structure and extract
only what I need - nothing comes close. Need it to code a complex app or write
a blog post - disappointing at best.

The more I insert the LLM - or even small language models, in a specific hole
in my project where nothing else fitted nicely before - the more it feels like
that is exactly what it is meant to be used for. No wierd edge cases, no
inconsistencies, no weird expectations. It almost feels like building software
felt like before - peaceful.
